# 页间 · QuietLeaf v3

> 一个免费安装到 iPhone 主屏幕、以 EPUB 沉浸阅读与英语查词为核心的私人 PWA 阅读器。
>
> **本项目是可试用的 v3 开发版本，不是已经通过 iPhone Safari 全面验收的正式产品。** 不需要 TestFlight、Apple Developer 年费或第三方账号。GitHub Pages 可以免费托管页面。所有上传的书籍保存在当前设备浏览器数据库中，而不是 GitHub。

## 01 · 要实现什么（WHAT）

本次根据需求确定：

1. **书架**：EPUB、PDF 共用一个「+」文件选择器，自动根据文件特征和格式解析，不要求分别进入导入页。提供封面 / 列表 / 分组三种视图、搜索、最近阅读；支持自定义书籍分组与简单排序。
2. **EPUB 阅读**：保留左右点击/滑动翻页、目录、进度保存、字号/行距/主题设置、文字选区划线和笔记。
3. **词典模式 A**：翻到英文书的一页后，自动筛选本页候选难词。**默认词典只显示一个词（紧凑条）**，点击「展开」后才显示词表。点击正文单词，紧凑条改为对应单词的释义。词典竖屏在页面底部、横屏在页面左侧；横屏默认左栏宽度缩至约 22%，以减轻正文挤压。
4. **笔记**：主导航「笔记」统一显示跨书籍的划线、想法与生词，支持筛选和 Markdown 导出。生词可以标记「已掌握」，以影响词典候选词过滤。
5. **收藏**：**仅收藏 http/https 网页链接**、名称和域名；点击「打开」在浏览器中访问。**不**抓取页面、不自动生成文章、不提供网页阅读模式、不保存网页离线副本。
6. **我的**：显示藏书数、读完数、估算阅读分钟数、阅读天数、划线/想法条数、生词数；词典水平、展开词数、隐藏已掌握单词等偏好集中放在「我的」中。阅读主题/排版/朗读的入口也可从「我的」打开。
7. **朗读**：选中文字或当前页可使用 iPhone 系统语音朗读；保留可选的 Google Cloud TTS 代理示例（见收费警告）。
8. **离线与备份**：Service Worker 缓存 PWA 页面；IndexedDB 保存书籍与笔记；提供带书籍文件的 JSON 数据备份与恢复（大书库会占用大量内存）。

## 02 · 为什么这么做（WHY）

- **默认只显示一个词**：小说阅读最重要的是正文可读性。词典与正文并列时，完整词表会严重挤压显示空间，所以先呈现一个低高度词条，用户主动展开才增加占用。
- **词典与正文同步**：学习英语原著时，换页后自动出现候选词，不必退出阅读、复制到词典应用。点击正文单词则优先查看自己真正想知道的词。
- **横竖屏自适应**：竖屏留出底部一小条，横屏使用左侧窄栏，保持肌肉记忆和稳定的阅读视线。
- **一本书只有一个导入入口**：用户无需关心 EPUB/PDF 技术细节；PWA 不支持像原生 App 那样注册为 iOS「用其他 App 打开」系统文件处理器，因此选择 iOS 文件选择器是更可靠的替代方案。
- **生词归入笔记、网页仅收藏链接**：减少主导航复杂度，避免额外的网页抓取、版权、跨域与离线问题。
- **Local-first**：无需自己的账号和服务器，可免费维护私人书架；而浏览器存储无法替代正规备份，因此需要导出。

## 03 · 怎么实现的（HOW / 技术结构）

```text
quietleaf/
├── index.html                 页面结构、四个主导航、阅读器和弹层
├── styles.css                 响应式排版；纵向底部词典、横向左栏词典
├── app.js                     EPUB/PDF、书架、词典、笔记、收藏、统计与备份
├── zip.js                     EPUB ZIP 解包（随项目离线提供）
├── dict.js                    离线英汉词典：下载、存入 IndexedDB、查词与词形还原
├── dict/                      离线词典数据（en-zh.json、version.json、ECDICT 许可证）
├── tools/build_dict.py        从 ECDICT 生成 dict/ 的脚本
├── sw.js                      PWA 离线静态资源缓存 (quietleaf-v3.1，联网优先、离线回退)
├── manifest.webmanifest       PWA 安装元数据
├── icons/                     主屏幕图标
├── google-tts-worker.js       可选的 Google Cloud TTS 服务端参考代码
└── README.md                  本文档
```

**数据：**
- IndexedDB 数据库 `quietleaf-library`、对象仓库 `books`：Blob 格式原文件、封面、书名、进度、注释、生词、分组。
- IndexedDB 数据库 `quietleaf-dict`：离线词典（首次联网打开时自动下载约 1.4 MB，之后只在 `dict/version.json` 变化时更新）。
- localStorage：`quietleaf-prefs`（阅读+词典偏好）、`quietleaf-shelf-mode`（视图）、`quietleaf-groups-v3`（分组名）、`quietleaf-favorites-v3`（网址）、阅读时长和阅读日期。
- PWA 静态文件由 Service Worker 缓存。**缓存应用外壳不等于缓存在线释义或 Google TTS**。

**词典细节与局限：**
- 阅读页使用多栏 CSS 分页，每次翻页提取可见文字中的英文单词。
- **离线英汉词典**：来自 [ECDICT](https://github.com/skywind3000/ECDICT)（MIT 许可）的精简版，约 4.5 万词，另有约 3.6 万个变形（went→go、meandered→meander）指向原形。每词保留音标、最多三行中文释义和难度等级 1–5（中学 / CET-4 / CET-6·考研 / 雅思·托福 / GRE·罕见词，取考试标签与词频的较低者）。
- **本页难词**按难度等级筛选：「基础」显示等级 ≥3，「中级」≥4，「高级」只显示 5；同一单词的不同变形合并为一个。词典里没有的词（多为人名地名）不进入候选。词典未下载完成前，回退到旧的按单词长度估计。
- **点词查询**先查离线词典（自动还原词形），查不到才联网查 dictionaryapi.dev 英英词典。「我的 → 词典偏好」底部显示词典状态，可手动重新下载。
- **更新词典**：下载 `ecdict.csv` 后运行 `python3 tools/build_dict.py ecdict.csv`，并把脚本中的 `VERSION` 加一，提交 `dict/` 即可；用户联网打开 App 时会自动更新。
- 当前页可见文字抽取在复杂 EPUB（多层标签、脚注、特殊分栏、图片）上可能不准确，少数情况下翻页后词表可能包含相邻栏的内容。
- 默认紧凑词典只显示一个候选词；即使展开后关闭，下次新书的默认值仍为紧凑模式。词表最多显示 5 / 8 / 30 个（“全部”设为最多 30 个以保护性能）。

**阅读统计的口径：**
- 阅读时间是读书页面处于前台时每 15 秒增加一次的粗略估计，并非精确活跃阅读时间；不追踪实时视线/点击。少于 15 秒的会话可能不计入。
- 阅读天数是至少记录过一个 15 秒阅读区间的本机日期总数。
- 已读完是 EPUB 的已保存近似进度达到 99.5% 的书籍数；PDF 因第一版只手动保存页码，不能可靠计算是否读完。
- 统计不经任何云端同步，不提供跨设备同步。

## 04 · 如何开发、预览与安装到 iPhone（免费）

**在电脑本地预览：**

```bash
cd quietleaf
python -m http.server 8000
```

电脑浏览器打开 `http://localhost:8000`。需要让浏览器允许本地 IndexedDB。请勿直接双击 `index.html`，因为 `file://` 不等同于真实网站环境。

**部署 GitHub Pages：**

1. 在 GitHub 建立一个**公开**仓库，例如 `quietleaf-reader`。
2. 将 ZIP 内 `quietleaf/` 中的 `index.html`、`app.js`、`styles.css`、`zip.js`、`sw.js`、`manifest.webmanifest` 和 `icons/` 上传到仓库根目录。README 也建议一起提交。`google-tts-worker.js` 只是服务端示例，不需要部署到 Pages。
3. 在仓库 **Settings → Pages → Build and deployment → Deploy from a branch** 选择 `main` / `/(root)` 并保存。
4. 访问 `https://你的用户名.github.io/quietleaf-reader/`。
5. 在 iPhone 的 **Safari** 打开该地址，通过 Safari「分享 → 添加到主屏幕」安装。首次保持联网，等待页面资源缓存。
6. 打开主屏幕图标，点击「我的书架」旁的 `+` 选取 EPUB/PDF。后续可离线打开已导入书籍。请保存原始图书文件。

**从 v2 升级：**
- 使用**原仓库、原网址、原浏览器主屏幕图标**替换前端文件。v3 继续使用同名 IndexedDB 数据库和书籍对象仓库，旨在保留 v2 数据。
- Service Worker 版本为 `quietleaf-v3.1`，采用「联网优先、离线时用缓存」，部署新版本后联网打开即可拿到更新。如果仍显示旧页面，联网关闭再重开应用，必要时在 Safari 访问原网址刷新。**不要为强制升级而清除网站数据**，那会删掉书籍与笔记。
- 重要书籍在升级前建议保留原文件并导出笔记；浏览器无法保证在所有机型和异常情况下零数据损失。

## 05 · 用户操作速查

| 页面 | 操作 | 效果 |
|---|---|---|
| 书架 | 「我的书架」旁的 `+` | 单次选择一个或多个 EPUB/PDF 文件，自动解析 |
| 书架 | 封面 / 列表 / 分组 | 切换展示方式（记住偏好） |
| 书架 | 书籍 `···` | 继续阅读、加入/移出分组、删除 |
| EPUB 阅读 | 点击正文左右空白区域 | 上一页 / 下一页 |
| EPUB 阅读 | 轻点英文单词 | 显示对应单词详细释义（原词典位置） |
| EPUB 阅读 | 词典「展开」 | 显示本页更多候选词，点击「收起」恢复紧凑条 |
| EPUB 阅读 | 长按选中文字 | 划线 / 写想法 / 朗读 / 查词 |
| 笔记 | 选择「生词」 | 浏览跨书生词、标记已掌握 |
| 收藏 | 输入网址并收藏 | 保存网址与可选标题，不下载网页 |
| 我的 | 词典偏好 | 设置词汇水平、词数上限、隐藏已掌握 |
| 我的 | 数据备份 / 恢复 | 导出/导入含原书的 JSON 文件 |

## 06 · 已知限制（请先阅读）

- **尚未在真实 iPhone Safari 上通过端到端测试**；尤其横竖屏栏宽、动态键盘、触摸选词与 iOS 后台生命周期需要实机验收。
- PDF 目前仍使用浏览器原生预览：不保证每台 iPhone 都能完整内嵌显示，暂不提供 PDF.js 文字层、PDF 选词查词或高亮笔记，也无法精确统计 PDF 阅读进度。
- 不支持 DRM 加密 EPUB、扫描 PDF OCR。
- 左右点击与原生长按选字可能在某些排版里产生手势冲突；需要按具体 EPUB 排查。
- 没有阅读云同步；Safari 清除站点数据、卸载/迁移 App 或系统回收存储，都可能使数据丢失。备份文件含书籍全文与个人笔记，注意私密保存。
- 备份 JSON 会把图书二进制转为 Base64；大型书库导出可能造成浏览器内存不足、耗时较长，建议控制单次书库体量并保留原始图书文件。
- 网页收藏只保存 URL 和显示名称，并不缓存网站内容，不保证离线打开网站。
- 系统 TTS 免费，但 iOS 锁屏/后台朗读可能中断；在线查词和 Google Cloud TTS 需要网络。
- 可选 Google Cloud TTS **不是永久免费**：必须自行开通 Google Cloud 项目、结算、服务端密钥及代理，可能产生费用。避免将服务密钥写入前端。

## 07 · 可选 Google Cloud TTS 安全配置

如果无需 Google Cloud 音色，**无需配置，默认系统语音就可以朗读**。如果需要 Google Cloud：

1. 自行创建 Google Cloud 项目，开通 Cloud Text-to-Speech API 与结算，设置配额和预算提醒。
2. 将 `google-tts-worker.js` 部署到 Cloudflare Workers。将 `GOOGLE_TTS_API_KEY`、`TTS_ACCESS_TOKEN` 配置为 Worker 加密 secret，`ALLOWED_ORIGIN` 设置为你的 Pages 的 origin（如 `https://username.github.io`）。
3. 在阅读器「我的 → 字体、主题与朗读设置」中选择 Google TTS，填写 HTTPS Worker URL 和私人访问口令。
4. 切勿提交密钥到 GitHub。客户端口令仍会存在本机 localStorage 中，适合私人可信设备，不适合提供给不信任用户。

## 08 · 验证情况与待办

已做：JavaScript `node --check` 语法检查、静态文件结构检查和 ZIP 完整性检查。

尚未完成：当前运行环境阻止浏览器导航到本地服务和 `file://` 页面，因此未能完成自动化浏览器端到端测试；也未对真实 iPhone 进行安装/触摸/旋转测试。请先用演示 EPUB、小型 PDF 与一条测试网站链接在 Safari 上验证，再导入重要资料。

后续优先级：修正复杂 EPUB 的可见文字识别、使用稳定 EPUB CFI 进行跨排版笔记定位、PDF.js 文字层查词、完整的离线词典与更准确的词汇等级数据。
