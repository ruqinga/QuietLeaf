# 页间 · QuietLeaf

**中文** | [English](README.en.md)

一个安装在 iPhone 主屏幕上的私人阅读器：读英文原版书时，自动列出当前页的生词，点一下就能看释义、听发音、收进生词本。书和笔记都只保存在你自己的手机上。

**👉 打开阅读器：<https://ruqinga.github.io/QuietLeaf/>**

---

## 安装到 iPhone

1. 用 **Safari** 打开上面的链接。
2. 点底部的「分享」按钮 → 「添加到主屏幕」。
3. 之后都从主屏幕上的「页间」图标打开。
4. 第一次打开时请保持联网，阅读器会在后台下载离线词典（约 1.4 MB）。下载完成后，没有网络也能查词。

> 主屏幕 App 和 Safari 网页的数据是分开的。请固定用主屏幕图标打开，否则在一边导入的书，另一边看不到。

## 书架

- 点「我的书架」右边的 **＋**，选择 EPUB 或 PDF 文件导入，一次可以选多本。
- **封面 / 列表 / 分组**：切换书架的显示方式。
- 搜索框可以按书名、作者查找；「最近阅读 ↓」可以切换成按书名排序。
- 点书本上的 **···**：继续阅读、加入或移出分组、删除。

## 阅读

| 操作 | 效果 |
|---|---|
| 点屏幕左侧 / 右侧，或左右滑动 | 上一页 / 下一页 |
| 点屏幕中间 | 显示 / 隐藏菜单（返回、笔记、朗读、目录、字体设置、阅读进度） |
| 点正文里的英文单词 | 在词典栏显示释义和音标 |
| 长按文字 | 选中这个词（按住继续滑动可以扩大范围，拖动两端的蓝色手柄可以调整），旁边弹出工具条：点颜色圆点即划线（黄 / 绿 / 蓝 / 粉），或写想法、复制、问 AI、查词、朗读 |
| 点已划线的文字 | 换颜色、复制、编辑想法、朗读、删除 |

在「Aa」里可以调整主题（纸张 / 暖黄 / 深夜）、字号、行距、字体和朗读速度。阅读进度会自动保存。

**朗读语音**：默认用 iPhone 系统语音，免费，离线也能用。如果想要更自然的声音，可以在 **我的 → 朗读语音** 里选 **Google Cloud TTS**：

- **API Key 直连**：填你自己的 Google Cloud API Key 就能用；英文、中文音色可以留空，也可以自己指定，比如 `en-US-Neural2-F`。点「试听」可以先听效果。
- **自建代理**：如果不想把 Key 存在手机上，可以用仓库里的 `google-tts-worker.js` 部署一个代理，再填代理地址。

使用 Google TTS 需要在 Google Cloud 开通 Text-to-Speech API 并绑定结算，超出免费额度会收费。建议把这个 Key 限制为只能调用 Text-to-Speech。Key 只保存在本机，不会进入数据备份。

## 本页词汇

翻到英文书的一页时，阅读器会按单词在正文中出现的顺序，自动挑出这一页的难词。

- **竖屏**：词典栏在屏幕底部，平时只显示一个词，点「展开」可以看本页全部难词。
- **横屏**：词典栏在左侧，一直列出本页所有难词，可以上下滑动。
- 每个词都会显示**音标和中文释义**：
  - 点这一行：读出单词，并在上方显示完整释义。
  - 点 🔊：只发音。
  - 点 ☆：加入生词本，星星变成实心 ★；再点一次取消收藏。
- 变形词会自动还原成原形，比如 meandered 显示为 meander。

列出哪些词，在 **我的 → 词典偏好 → 本页难词词表** 里选：

| 词表 | 显示哪些词 |
|---|---|
| 雅思 IELTS（默认） | 本页属于雅思词表的词，已去掉中考、高考的基础词（约 3300 词） |
| 雅思 IELTS · 跳过四级词 | 在上面基础上再去掉四级词（约 2300 词） |
| 托福 / GRE / 六级 / 四级 / 考研 | 对应考试词表里的词，同样去掉中学基础词 |
| 按难度：基础 / 中级 / 高级 | 旧版的难度分级方式 |

词表标签来自 ECDICT。

还可以设置竖屏展开时最多显示几个词，以及是否隐藏已经掌握的生词。

## AI 问书

可以接入你自己的 AI 账号，边读边问。

**设置**：在 **我的 → AI 助手** 里选服务商，填入你自己的 API Key，然后点「测试连接」确认能用。

| 服务商 | 默认模型 | 说明 |
|---|---|---|
| Claude（Anthropic） | `claude-opus-5-5` | 使用 Anthropic 官方 SDK |
| OpenAI（GPT） | `gpt-4o-mini` | 模型名可以改 |
| DeepSeek | `deepseek-chat` | 接口地址已预填 |
| 其他（OpenAI 兼容接口） | 自己填 | 填接口地址和模型名，适合其他兼容 OpenAI 格式的服务 |

模型名都可以改成你账号里能用的任意模型。每个服务商的 Key 分开保存，切换时不用重新填。

**三个入口**：

- **选中文字 → 问 AI**：解读这一段。可以点快捷问题（解释这段话、翻译成中文、分析句子结构、相关背景知识），也可以自己输入问题。
- **词典栏的「✦ 问 AI」**：问当前这个单词在这里是什么意思、怎么用、和近义词有什么区别。
- **顶部菜单的 ✦**：针对整本书提问，比如总结这一页、本章讲了什么、梳理人物关系。

回答会边生成边显示，可以继续追问，AI 会记得前面聊过的内容。生成时点「停止」可以中断。对选中文字的回答可以点「存为想法」，连同原文一起存进笔记。

AI 会知道书名、作者、当前章节和你选中的段落，并且被要求不剧透你还没读到的内容。

**隐私与费用**：Key 只保存在这台设备上，不会进入数据备份。提问时，选中的文字、所在段落、书名和章节会直接从你的手机发给你选的服务商，按对方的价格计费。

## 笔记与生词本

底部导航的「笔记」页汇总了所有书的划线、想法和生词。

- **全部 / 划线 / 想法 / 生词**：切换要看的内容。
- **生词**页：
  - 可以按书籍筛选，也可以搜索单词或中文释义。
  - 每个生词都有音标、🔊 发音、○ / ✓ 标记已掌握、★ 取消收藏。
  - 已掌握的词，阅读时不会再出现在本页词汇里（可以在设置里关闭这个功能）。
- 点「导出全部笔记 Markdown」可以把笔记存成文件。

## 网页收藏

收藏常看的网站链接，比如词典网站、读书社区。

- 还没有收藏时，页面上直接显示填写框；有了收藏以后，点右上角的 **＋** 添加新链接。
- 只保存网址和名称，不会下载网页内容。

## 我的

- **阅读统计**：藏书数、读完的书、阅读时长、生词数、划线数、阅读天数。
- **词典偏好**：本页难词词表、显示数量、离线词典的状态，以及「重新下载」按钮。
- **数据与阅读**（点击展开）：
  - 数据存在哪里、占用多少空间、上次备份的时间。
  - 定期备份：开关、间隔天数、备份位置。
  - 字体、主题与朗读设置。
  - 导出或恢复完整数据备份。

## 数据安全，请务必看一下

- 书籍、笔记、生词都**只保存在这台手机上**，不会上传到任何服务器。
- 网页更新到新版本**不会**删除你的书。
- 下面这些操作会删除数据：
  - 删除主屏幕上的图标；
  - 在「设置 → Safari → 高级 → 网站数据」里删除这个网站的数据；
  - 换了网址打开。
- **定期备份**：在 我的 → 数据与阅读 里打开「定期备份」，天数可以自己填，默认每 7 天一次。
  - **iPhone**：iOS 不允许网页自己选文件夹，也不能在后台写文件。所以到了备份时间，打开 App 后书架顶部会出现「已 N 天没有备份 · 立即备份」。点「立即备份」→「存储到文件」→ 选一个文件夹（比如 iCloud 云盘）。iOS 会记住上次的位置。点「稍后」，明天会再提醒。
  - **电脑上的 Chrome / Edge**：可以点「选择备份文件夹」。到期后打开页面，会自动把备份写进这个文件夹，不需要任何操作。
  - 也可以随时点「立即导出完整数据备份」。换手机时，用「恢复数据备份」把备份导回去。

## 常见问题

**看不到新功能？**
联网状态下，把 App 从后台彻底划掉，再重新打开一两次。不需要清除网站数据。

**在 Safari 里打开，书不见了？**
主屏幕 App 和 Safari 的存储是分开的，书还在主屏幕 App 里。

**PDF 能查词吗？**
暂时不能。PDF 用的是系统自带的预览，只能翻页阅读，不支持划线和查词。

**有些书打不开？**
不支持带 DRM 版权保护的 EPUB，也不支持只有扫描图片、没有文字的 PDF。

**查词需要联网吗？**
不需要。离线词典有约 4.5 万词。离线词典里没有的词，联网时会再去查在线英英词典。
